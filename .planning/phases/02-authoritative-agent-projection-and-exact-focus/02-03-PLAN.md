<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Admitted snapshot → physical pixels/bindings | Valid wire data can still produce unsafe UI/action ordering unless staged atomically. |
| Physical key → focus intent | The action must capture the displayed identity before any subsequent snapshot changes the slot. |
| Host action result → tile feedback | Late, replayed, or mismatched outcomes must not alter visible state. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-03-01 | Tampering | sequential snapshot update | high | mitigate | Global non-actionable SYNC veil, fixed staging generation, sequential draws, and one final binding commit. |
| T-02-03-02 | Spoofing | slot reuse | high | mitigate | Copy exact committed opaque identity/source revision/epoch/revision into each focus intent. |
| T-02-03-03 | Spoofing | focus result | high | mitigate | Match every correlation field to the bounded pending record before feedback changes. |
| T-02-03-04 | Denial of Service | repeated physical input | medium | mitigate | Fixed pending capacity, duplicate suppression, bounded action IDs, and no queued replay. |
| T-02-03-05 | Elevation of Privilege | unbound controls | high | mitigate | Keys 1..3 emit only focus_intent for current bindings; key 4 and encoder have no Phase 2 action. |
| T-02-03-06 | Information Disclosure | tile rendering | low | accept | Only bounded title/discriminator/state and opaque IDs are stored; no path, prompt, transcript, or credential is rendered. |
