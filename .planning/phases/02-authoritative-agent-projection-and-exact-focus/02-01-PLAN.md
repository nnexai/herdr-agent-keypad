## Trust Boundaries

| Boundary | Description |
|---|---|
| Host normalized snapshot → USB protocol | Host-controlled but fallible data crosses into fixed-memory firmware and must be bounded before staging. |
| Rendered tile → physical key intent | Dynamic pixels must remain paired with the exact immutable binding generation. |
| Device result correlation → visible success | A stale or mismatched result must not be displayed as successful focus. |
