<interfaces>
Installed projection authority:
- Rank token values are strings `0` blocked, `1` finished/unseen or manual unread, `2` working, `3` idle, `4` unknown, `5` settled.
- Executable order is `(tokens.rank ascending, state_change_seq descending)`; `agent.list` array order is not authoritative.
- Metadata fields are nullable; required identity core is pane_id, terminal_id, workspace_id, tab_id, agent_status, focused, and per-record revision.

Herdr 0.8.0 public API:
- `session.snapshot` bootstraps complete workspaces/tabs/panes/agents; it has no bridge epoch or top-level revision.
- `events.subscribe` is an invalidation/refresh trigger, not a replacement snapshot stream.
- `agent.focus({target: pane_id})` returns `agent_info` on success; target miss returns `agent_not_found`.
</interfaces>
