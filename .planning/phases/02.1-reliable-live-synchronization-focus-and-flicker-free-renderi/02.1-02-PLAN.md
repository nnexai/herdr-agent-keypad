Remove progressive on-panel repaint from the accepted three-slot renderer while preserving the global generation fence: each panel receives one fully composed image, and pixels/bindings become current only after all three sequential flushes finish.

Output: Reused bounded sprite composition, native production-code renderer/state tests, generation-scoped feedback cleanup, selected-build metrics coverage, and fail-closed snapshot acknowledgement.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host normalized snapshot → firmware projection | Untrusted framed content becomes staged display data and hidden physical key bindings only after protocol and generation checks. |
| Firmware composition buffer → mapped physical panel | A complete in-memory image crosses to one STM32-selected display at a time. |
| Firmware focus result → pending visual state | A host result may affect pixels only if it matches the current pending generation and identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02.1-02-01 | Tampering | `AgentProjection::commitSnapshot(BoardAdapter&)` | high | mitigate | Keep bindings disabled through SYNC and all three composed flushes; activate only after complete staged generation success. |
| T-02.1-02-02 | Denial of Service | sprite allocation and panel flush | medium | mitigate | Allocate one bounded 128x128 RGB565 PSRAM sprite once, reuse it, fail the ACK and remain in SYNC on allocation/null-display failure, and measure heap/flush/key-gap values. |
| T-02.1-02-03 | Replay/Tampering | `applyFocusResult` and feedback timers | high | mitigate | Clear all pending/deadline state on generation change and retain exact action/epoch/revision/slot/identity matching before any feedback update. |
| T-02.1-02-04 | Spoofing | physical panel/key mapping | high | mitigate | Continue to resolve only slots 0..2 through verified `BoardAdapter::displayAt`; never address raw chip-selects or panel/key 4. |
| T-02.1-02-05 | Information Disclosure | tile composition buffer | low | accept | The buffer contains only the same bounded normalized title/discriminator/state already authorized for the panel and is reused in volatile memory without persistence. |
</threat_model>
