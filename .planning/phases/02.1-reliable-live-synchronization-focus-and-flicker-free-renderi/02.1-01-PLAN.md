## Trust Boundaries

| Boundary | Description |
|---|---|
| Herdr public AF_UNIX socket → host bridge | Typed but asynchronous external lifecycle data crosses into the authoritative refresh owner. |
| Paired USB device → host bridge | ACK and focus frames are untrusted until codec, boot/session, sequence, reply, generation, and identity checks pass. |
| Host bridge → FocusExecutor/Herdr | A physical intent approaches the only write capability, `agent.focus`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02.1-01-01 | Spoofing/Tampering | `HerdrEventStream` | high | mitigate | Correlate the subscribe ACK, admit only explicit typed bounded event envelopes, and use events only to trigger complete public-socket reads. |
| T-02.1-01-02 | Tampering/Replay | `UsbDeviceSession` ACK and pending FIFO | high | mitigate | Reuse codec/session admission; require exact boot/session/sequence/reply/epoch/revision; clear the bounded FIFO on every session end. |
| T-02.1-01-03 | Denial of Service | event burst and pending device frames | medium | mitigate | Drain at most 16 events per iteration, coalesce to one refresh plus one follow-up, cap pending focus frames at 16, and fail closed on overflow. |
| T-02.1-01-04 | Elevation of Privilege | `PermanentBridge.handle_frame` | high | mitigate | Preserve `FocusExecutor` as the sole dispatcher and retain its exact identity/generation validation and one-method `agent.focus` allowlist. |
| T-02.1-01-05 | Information Disclosure | normalized snapshot publication | low | accept | The existing closed payload carries only bounded display fields and opaque device identity; raw event bodies, paths, prompts, transcripts, and credentials are never forwarded. |
</threat_model>
