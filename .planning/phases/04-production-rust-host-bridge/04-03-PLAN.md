## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Port the closed wire contract and the authoritative projection/exact-focus state machines into a portable, allocation-bounded Rust core against the frozen fixtures.

Purpose: Preserve the two authorities most likely to cause an unsafe migration: what pixels mean and which exact pane a press may focus.
Output: Protocol, domain model, projection, focus modules, and differential tests.
</objective>
