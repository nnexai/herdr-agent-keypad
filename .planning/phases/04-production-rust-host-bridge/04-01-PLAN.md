## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Prove the hardest migration seam first: one production-quality Rust path that reads one authoritative Herdr agent, publishes and ACKs one complete device generation, accepts one exact focus intent, performs only `agent.focus`, and returns the correlated result.

Purpose: Establish the stable interfaces every parallel expansion plan consumes without adding a temporary runtime command or disposable architecture.
Output: A locked native crate, thin production entrypoint, durable core/port contracts, the original tracer execution record, and the maintained composed proof accepted below.
</objective>

## Current-state amendment: WR-01 clean-cutover supersession

The original task blocks below remain the execution record for commits `89e7462`, `e4fbccd`, and `25a0994`. They describe the early root `Coordinator` bootstrap and `tests/production_tracer.rs` as they existed when Plan 04-01 completed. They are historical, not current verification authority.

The Phase 04 closure review resolved WR-01 by removing that duplicate public coordinator, its unsafe unbounded Herdr socket reader, and the tracer coupled to the obsolete path. Production now composes only through `core::RuntimeCoordinator`. Restoring the deleted root path would reintroduce a second coordinator and violate the required clean cutover.

The accepted replacement is composed proof across maintained production boundaries:

| Exact projection binding and focus policy | `projection_focus_parity.rs`: `focus_policy_revalidates_exact_identity_and_allows_one_retry`, `focus_policy_maps_fences_and_failures_without_other_effects` |

| Production composition and lifecycle | `src/main.rs` constructs `core::RuntimeCoordinator`; `core/orchestrator.rs` joins complete reads, projection, matching ACK, exact focus, and shutdown; `production_surface.rs`: `production_binary_start_status_stop_owns_control_socket_for_authority_lifetime` |
