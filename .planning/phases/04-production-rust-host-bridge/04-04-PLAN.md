## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Implement the two host-source adapters as bounded event-driven ports against the frozen oracle, while leaving ordering, focus, freshness, and publication policy in the portable core.

Purpose: Preserve authoritative Herdr data and truthful Codex capacity without translating the Python bridge's polling loop or leaking upstream payloads.
Output: Herdr and Codex adapters plus focused differential tests.
</objective>
