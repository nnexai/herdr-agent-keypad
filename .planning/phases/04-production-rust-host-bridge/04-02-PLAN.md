## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Freeze the migration contract before horizontal expansion by exporting deterministic black-box traces from the Python oracle and validating their schema, bounds, privacy, and root-protocol lineage.

Purpose: Prevent a plausible Rust rewrite from silently changing observable ordering, focus, Codex, protocol, recovery, or diagnostic behavior.
Output: Four dedicated fixture corpora, one exporter, and one independent Rust fixture validator.
</objective>
