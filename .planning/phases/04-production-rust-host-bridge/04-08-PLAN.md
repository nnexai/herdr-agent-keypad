## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Perform the narrow production cutover after runtime integration: bundle an executable lifecycle/recovery procedure, switch the Herdr manifest to direct native startup/actions, and retire the shell launcher.

Purpose: Make install, update, removal, and failed-update recovery operationally complete without mixing packaging metadata into the runtime integration plan.
Output: Tested bundled lifecycle document, direct-native plugin manifest, cutover test, and deleted legacy launcher.
</objective>
