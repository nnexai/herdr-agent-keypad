## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Integrate every parallel Rust slice, lock the final crate, wire the event-driven coordinator, and cut the Herdr plugin production path from Python/shell to the bundled native executable.

Purpose: Establish one production authority and remove migration-only launch surfaces only after focused parity slices are complete.
Output: Integrated crate, production coordinator/entrypoint, final dependency lock, native plugin manifest, and retired shell launcher.
</objective>
