## Phase goal

**As a** keypad user, **I want to** run the complete host bridge as one native Rust executable, **so that** inbox, focus, Codex, recovery, and focus-authorized hold behavior no longer depend on a Python runtime.

<objective>
Build, test, inspect, and package native Linux x86-64 and macOS Apple Silicon plugin artifacts with reproducible unsigned evidence and no runtime or privacy leakage.

Purpose: Turn the integrated binary into installable target packages without overstating signing/notarization or adding another distribution/runtime authority.
Output: Native release workflow, closed bundle schema, verifier, and focused release tests.
</objective>
