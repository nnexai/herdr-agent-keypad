## Phase goal

**As a** user of the keypad, **I want to** hold an agent key after exact focus, **so that** ordinary applications receive one real system-wide held Space input without CLI-specific integration.

<objective>
Add restrained, truthful hold feedback to all four existing display themes while retaining the established focus and source-failure hierarchy.

Purpose: The user must know which physical key can end a system-wide held input without mistaking pending focus, cancellation, or failure for an active keyboard state.
Output: Normalized hold presentation, four theme-owned mic treatments, deterministic capture scenes, and native geometry/precedence coverage.
</objective>

- Four theme-specific outlined and solid mic treatments.
