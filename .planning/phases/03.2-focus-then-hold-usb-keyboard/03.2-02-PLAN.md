## Phase goal

**As a** user of the keypad, **I want to** hold an agent key after exact focus, **so that** ordinary applications receive one real system-wide held Space input without CLI-specific integration.

<objective>
Harden the production tracer at the physical-input, USB lifecycle, pairing/session, and evidence boundaries.

Purpose: A keyboard feature is acceptable only when release and session changes are stronger than the happy path. This plan makes every release/lifecycle path explicit and measurable without weakening CDC or focus authority.
Output: One-poll BoardAdapter lifecycle, release-all precedence, measured composite discovery/udev migration, fixed proof metrics, and focused board/host/protocol coverage.
</objective>
