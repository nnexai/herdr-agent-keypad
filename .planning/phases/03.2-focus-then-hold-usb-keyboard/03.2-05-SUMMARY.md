## Normalized Field Contract for Plans 06 and 07

| Field | Meaning | Producer/authority | Clear/suppress rule |
|---|---|---|---|
| `slots[i].hold_candidate` | A bounded candidate exists on physical slot `i` and ordinary focus feedback permits its presentation. | `HoldController::PresentationState::candidate_slot`, copied by `AgentProjection`. | False after physical candidate release/cancellation, named failure, source fence, projection sync, lifecycle block, or generation fence. |
| `slots[i].hold_threshold_qualified` | The candidate on slot `i` crossed the measured threshold. | `PresentationState::threshold_qualified`. | False whenever candidate presentation is suppressed; never authorizes HID. |
| `slots[i].hold_active_owner` | Space is actually down for physical slot `i`. | `PresentationState::owner_slot`; completed HID down remains the only producer fact. | False on physical release, lifecycle clear, failed release path, source/failure presentation fence, or absent occupied binding. |
| `hold_lifecycle_cleared_epoch` | Monotonic lifecycle-clear observation epoch. | `PresentationState::lifecycle_cleared_epoch`. | Exposed as an observation only; no projection-side reset or mutation. |
| `hold_lifecycle_blocked` | Lifecycle rearm is blocked pending safe empty report and all-keys-up conditions. | `PresentationState::lifecycle_blocked`. | Presentation remains suppressed while true. |
| `hold_empty_report_complete` | The latest lifecycle empty-report attempt completed. | `PresentationState::empty_report_complete`. | Presentation remains suppressed while false. |

## Precedence Matrix

| Condition | Normalized hold presentation | Ordinary focus feedback |
|---|---|---|
| Candidate pending or threshold-qualified | Candidate/threshold facts may show on the candidate slot. | Existing `Pending`/`Success` vocabulary remains visible. |
| Threshold-crossed release before acknowledgment | Candidate and threshold facts clear immediately. | Returns directly to ordinary `Pending`; no cancellation tile state is added. |
| Pre-threshold release | No candidate or owner facts. | Ordinary focus-only feedback remains unchanged. |
| Rejected, stale, vanished, offline, uncertain, timeout, or failed result | Candidate and active-owner facts are suppressed before the complete output frame. | Existing named failure feedback remains authoritative. |
| Source status other than `current` or projection sync | All candidate/owner facts are suppressed. | Existing source/sync rendering remains authoritative. |
| Session loss, controlled reset, STOPPED, suspend, resume | Candidate/owner facts clear through the passive lifecycle block. | Existing source/focus feedback is not replaced. |
| HID down failure | Candidate is cleared before the failed attempt; no owner is exposed. | Existing focus feedback remains unchanged. |
| HID up/release-all failure | Owner clears before the failed report; lifecycle remains blocked and empty completion is false. | Existing feedback remains unchanged. |
| Another slot focuses or a generation is replaced | Existing physical owner remains on its occupied physical slot until Plan 03 reports physical/lifecycle release. | Other slot's focus feedback and generation commit proceed normally. |
