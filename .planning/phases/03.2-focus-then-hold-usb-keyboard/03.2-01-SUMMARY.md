## Decisions Made

- Plan 00's exact measured shared threshold is compiled as 550 ms and starts at the debounced edge, not focus-result or CDC time.
- `AgentProjection::applyFocusResult()` remains the only authorization fact; the wire schema and host focus/session API are unchanged.
- A local owner outlives later focus changes but never transfers; its physical release has priority and immediately emits release-all.
- Same-poll chords are permanently focus-only for that physical set until a complete all-up frame, including after disconnect/session cancellation.
