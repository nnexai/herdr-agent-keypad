- `ProductInputFrame` is a small captured-value struct. `ProductInputRouter` is a pure fixed-capacity ordering module, not another controller: it owns no hardware, menu state, focus state, queue, timer, binding, or action authorization.
- Production `main.cpp` captures agent key edges, encoder click, and encoder delta once after `board.update()`, routes that frame, and dispatches every returned agent action before any encoder/menu action.
- `MenuController` owns menu state, candidates, viewport, and deadline only. It receives encoder actions from the production router and never sees keys 1-3.
- `SettingsStore` remains the only NVS boundary. `BoardAdapter::setBrightness()` remains the only brightness hardware seam.
- The existing `captureFocusIntent` and focus-only protocol path remain the sole direct-agent action path.
</interfaces>
