# Plan 02.2-01 Summary — Theme seam, per-panel reveal, feedback split, NVS settings

## What was built

- **`firmware/src/ui/render_state.h`** — shared `RenderState` POD (per-slot occupied/title/discriminator/`TileState`/`TileFeedback`, global `source_status`/`syncing`) plus `ThemeId`/`LedGrammarId` enums. `TileState`/`TileFeedback` are now top-level enums; `AgentProjection::TileState`/`Feedback` alias them so all existing callers compile unchanged.
- **`firmware/src/ui/theme.h`** — `ThemeRenderer` interface: `composeTile`, `composePanel4`, `composeMenu` (stub → rest composition until plan 04), `composeSync`, `ambientTick` (returns dirty-slot mask; 0 for now). `themeById()` resolves every id to Signal Edge until plan 02 lands the other three languages.
- **`firmware/src/ui/theme_signal_edge.cpp`** — full UI-SPEC anatomy: state rail width+pattern per state (solid/thin/3-1-3 stripes/dashes/hollow/dotted/none), two-row ellipsized title, discriminator, 30 px stroke glyphs, state word, bottom feedback band y:108..128 with literal cause words, fence desaturation + red band for stale/offline/unavailable, dashed-container empty tile, honest panel-4 `CODEX`/`UNAVAILABLE`/`NO VALUES` composition with hatched gauges.
- **`AgentProjection`** — presentation moved behind the theme pointer; staging/commit/binding/feedback logic untouched. `commitSnapshot(BoardAdapter&)` no longer paints a SYNC veil between committed generations (per-panel direct cut, R-2); flush failure mid-reveal falls back to SYNC on all panels and rejects the commit. Success feedback uses new `kSuccessHoldUs` (800 ms); failure family keeps `kFeedbackHoldUs` (2 s).
- **`SettingsStore`** (`firmware/src/app/settings_store.{h,cpp}`) — NVS namespace `keypad`, keys `ver`/`theme`/`ledgram`, schema v1. `load()` validates; anything invalid → Signal Edge + Rail Echo with **no write-back**. `confirm()` is the only write path (version first). Wired into `setup()` after `board.begin`.
- **REQUIREMENTS.md amendments** — SYNC-02 restated as actionable-binding atomicity with per-panel reveal (R-2, cites D-16); decorative-animation exclusion replaced by the measured-budget rule (R-1, cites D-13/D-14). Both dated 2026-08-18.
