# Phase 02.2 — UI Design Contract

> Visual and interaction contract for the four selectable display languages, four selectable LED grammars, and the panel-4 encoder settings menu on the connected LILYGO T-Keyboard S3 Pro. This contract extends — and where explicitly stated amends — the Phase 2 UI contract (`02-UI-SPEC.md`). The design source of record is `.planning/research/DESIGN-PROPOSALS.html`; this document binds its behavioral specs to the firmware seams.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — embedded C++ firmware (LovyanGFX primitives through the existing composition sprite) |
| Preset | not applicable |
| Component library | none; existing `AgentProjection` state + shared 128×128 RGB565 composition sprite + `BoardAdapter` flush path |
| Icon library | none; drawn primitives only (filled triangle/disc, ring, cross, corner, question, dash, check, spinner-ring) — never font glyphs |
| Font | existing bitmap mono family; T1 title/state at 10–12 px cell (8 px cap), T2 meta at 8 px cell (5×7 glyph) hard floor |

The shadcn gate does not apply (embedded firmware). No second display abstraction, no raw chip-select access, no LVGL, no remote assets.

### Amendments to the Phase 2 contract (explicit)

1. **Ambient motion is permitted** under the measured animation budget in `02.2-RESEARCH.md` R-1. The Phase 2 "no decorative animation" rule is superseded for theme-specific ambient motion that (a) is composed-then-flushed as complete frames, (b) never obscures or delays semantic states/fences/feedback, and (c) degrades to static frames when the measured budget is exceeded. BLOCKED keeps its privileged 1.2 s pulse, in phase with LEDs.
2. **Per-panel progressive reveal is permitted** under R-2: bindings stay all-panel atomic; pixels flip old-complete → new-complete per panel sequentially (≤ 250 ms total); SYNC veil remains only for boot/session-reset/failure.
3. **Panel 4 becomes an active surface**: each theme's Codex/health composition renders its honest UNAVAILABLE state (no live Codex data exists until Phase 3), and the encoder settings menu overlays panel 4.
4. **Success feedback hold shortens to ≈ 800 ms** (D-15). Failure-family holds keep the existing bounded 2 s / until-newer-generation behavior.

Everything else from `02-UI-SPEC.md` remains binding: 4 px safe inset, host authority, identity-bound focus, literal words for every state, no color-only meaning, truthful absence, bounded ASCII copy, no credentials/paths/transcripts on device.

## Shared State Contract (all four themes)

Every theme renders the complete vocabulary. Colors, glyphs, and each theme's mandatory non-color channel:

| State | Color | Glyph | A: rail | B: typography | C: field/glyph | D: ring stroke |
|---|---|---|---|---|---|---|
| BLOCKED | #F7768E | ✕ heavy | 16 px animated dashes (1.2 s crawl) | solid rose inversion band | field+glyph breathe 1.2 s | heavy dashed, breathing |
| UNSEEN | #7DCFFF | ● filled | 3-1-3 doubled stripes | double underline + blue hairline | blue field, steady | double ring |
| WORKING | #E0AF68 | ▶ triangle | 16 px solid | full-weight underline | amber field, steady | solid 3 px |
| IDLE | #9ECE6A | ○ ring | 8 px thin | 2 px underline | flat black field | thin 1.5 px |
| SETTLED | #565F89 | ⌜ corner | hollow outline | grayed row, 1 px hairline underline | flat field, corner glyph | hairline |
| UNKNOWN | #565F89 | ? mark | dotted | dotted underline; missing meta as "—" | flat field, question glyph | dotted |
| EMPTY | #263648 | — dash | no rail, dashed container | hairline + "SLOT EMPTY" | dashed border, no field/title | dashed hairline ring |

Feedback layer (never a resting state): PENDING cyan #22D3EE animated ellipsis/spinner steps ≥ 300 ms; FOCUSED lime ✓ held ≈ 800 ms then cut back; failure family red #EF4444 (UNCERTAIN amber !) with the exact cause word — REJECTED / VANISHED / STALE / OFFLINE / FAILED / UNCERTAIN, never a generic error. Feedback vehicles per theme: A bottom band (y:108..128, opaque, title stays visible) · B header band takeover (y:0..18, opaque, 9 px bold ink caps) · C center takeover (glyph swap + 55 % field dim, title stays) · D ring recolor + state line.

Source health fencing: STALE/OFFLINE/UNAVAILABLE desaturate + dim content, pin the reason in the theme's feedback vehicle, and fence focus. A: desaturate + red band; B: persistent red header band absorbing the discriminator; C: desaturate + bottom fence line (+ red top hairline for OFFLINE across all panels); D: all four bezel ticks red on every panel simultaneously. Old identity remains readable but unmistakably fenced.

Discriminator format everywhere: `workspace·tab` (fallback `workspace·agent-type`, then `NO WORKSPACE`), budgeted ~13 chars at the 8 px floor, tail-ellipsized. "since"/"age" are verbatim source strings, never recomputed on device.

## Theme Anatomies (device pixels, inside the 4 px inset)

### A · Signal Edge (default; safe fallback for invalid stored settings)

- State rail x:0..15 (or 0..7 thin), full height; width + fill pattern is the state channel.
- Title x:15..123 y:5, two rows 12 px cell, ellipsized. Discriminator x:15 y:32, 8 px cell.
- State glyph centered x:16..128 y:44..76, 30 px stroke primitive, rail hue.
- State word x:15 y:110 10 px bold caps + "since" right-aligned 8 px meta. Feedback band replaces y:108..128.

### B · Ledger

- Header y:5..16 (disc left, age right, 8 px meta), hairline y:16.
- Title x:6..122 y:22, two 12 px-cell rows. Optional detail line y:52 (seq/revision; off by default, menu-toggleable "diagnostic density").
- State row y:72..88: glyph 15 px + word 11 px bold caps with 5 px state-hue underline + since right. BLOCKED inverts the row to a solid rose band.
- Footer y:116: slot dots right (●●○ = slot 2/3); left side reserved for one-line feedback reasons.

### C · Beacon

- since top-right 8 px meta. State glyph centered 44 px on radial field (24 % state hue at center → black at edges; flat black for calm states).
- State word y:73 10 px bold tracked caps. Title strip y:100..122: one title line + one identity line, centered, ellipsized.
- RGB565 banding risk: use stepped bands or ordered dither if smooth radial gradients band on hardware.

### D · Instrument

- Four 6×6 px corner bezel ticks, line-gray (red = health channel, all panels at once).
- Header y:4 centered 8 px caps discriminator. State ring centered ⌀64 (shrink to ⌀56 if crowded), stroke style per state, glyph 26 px inside.
- State line y:89 9 px bold caps "WORD · SINCE". Meta line y:102 reserved for feedback reasons. Title y:112 centered, ellipsized.

## Panel 4 (per theme, Phase 02.2 scope)

No Codex collector exists in this phase. Panel 4 at rest renders the active theme's honest no-data composition: title `CODEX`, hatched N/A gauges/dial per theme geometry, and `UNAVAILABLE` — never fabricated percentages, never 0 % for null. Theme-specific compositions (stacked gauges / ledger numbers page / conic dial / twin gauges with 75 % warn tick) ship as renderers now so Phase 3 only wires data. When the menu is open it overlays panel 4 entirely.

## Encoder Settings Menu (panel-4 overlay)

- **Open/close:** encoder click toggles. Keys 1–3 remain live direct focus paths at all times (non-modal, D-10).
- **Rows (this phase only):** `THEME` and `LED`. Rotation moves a bounded cursor, clamped at first/last row (no wrap, D-12). Click enters a row; rotation cycles its four values; click confirms; a second click on the row header (or close) without confirm discards the preview.
- **Preview then confirm (D-04):** while cycling THEME values the menu itself re-renders in the candidate theme's menu style; the agent tiles and panel-4 rest composition do not preview. Confirmation via click persists; close-without-confirm reverts to the stored value. LED row previews by driving the strip with the candidate grammar live; same confirm/revert rule.
- **Menu style per theme:** rendered in the active (or previewed) theme's language — A: 8 px rail + full-row selection band, with two bounded mode hints (`TURN: SELECT` / `CLICK: ENTER` or `TURN: CHANGE` / `CLICK: SAVE`); B: ledger list with `>` cursor row highlighted; C: large row words; D: bezel + rows with `TURN:SEL CLICK:CLOSE`. All copy stays inside the 4 px safe inset and never crosses a rail or bezel.
- **Persistence (D-11):** only explicitly confirmed theme + LED grammar are written (NVS, schema-versioned). Invalid/missing stored values → Signal Edge + Rail Echo, not written back.
- Encoder indication: the active LED grammar's menu-open cue (backlight L13 lit while open, per grammar rules).

## LED Grammars (14-pixel strip; logical indices via PhysicalMap)

Physical zones: backlights L1/L4/L7 (agent keys), L10 (usage/K4), L13 (encoder); above-key accents L0/L3/L6/L9; inter-key accents L2/L5/L8/L11/L12. Zones are dedicated with deterministic overlays (D-06): per-key state in its key zone, usage in the usage zone, health in the grammar's documented health zone, menu-open on the encoder indication, focus feedback overriding only its own zone.

| Grammar | Resting | Health (stale/offline/unavailable) | Focus feedback (bounded, D-08) | Menu open |
|---|---|---|---|---|
| A · Rail Echo | backlights mirror tile state: BLOCKED 40 pulse · UNSEEN 30 · WORKING 18 · IDLE 8 · else off; accents always dark | all backlights breathe dim red ≤ 10 in unison | pressed backlight cyan 45 during PENDING; lime ×2 on FOCUSED; red ×2 on failure; then return | L13 lit while open |
| B · Exception Channel | dark unless action: BLOCKED backlight rose 30 breathe; UNSEEN blue 20; nothing else | above-key accents L0/L3/L6/L9 dim red 10; backlights keep meaning | minimal: single short pressed-backlight blink (cyan pending / lime success / red failure) — bounded extension per RESEARCH note | L13 lit while open |
| C · Field Extension | 3-LED halo per key (K1:0-1-2 · K2:3-4-5 · K3:6-7-8 · usage:9-10-11) in state hue; backlight brightest, halo 40/60 % of it; ladder 38/28/16/8 | all halos off; encoder pair L12-L13 breathes red 10 | halo sweep 0→1→2 cyan during PENDING; solid lime ×2; red ×2 | L13 lit (health owns L12-L13 pair; menu cue yields to health) |
| D · Meter + Lamps | backlights as grammar A; accents L0-L2-L3-L6 = 4-step usage meter — **all off in 02.2 (honest: no usage data)**; L5/L8/L9/L11/L12 permanently dark | lamps unison dim red; meter dark | lamp blink as grammar A; meter untouched | L13 lit while open |

Power policy (defaults per D-07, enforced by one shared engine): global cap 45, resting ≤ 25, ≤ 6 LEDs above 25 simultaneously, no persistent white, unison-red health ≤ 10, dim mode scales all ≤ 8, all-off is a single mask write. BLOCKED LED pulse period 1.2 s, in phase with on-screen BLOCKED motion. Real-unit brightness sighting happens in the device smoke; ladder values may be adjusted from measurements, structure may not.

Multi-hue frames are emitted as a bounded ordered list of (mask, hue, sat, brightness) segments through `BoardAdapter::setLeds`; segment count is a compile-time bound.

## Motion Contract (amended charter)

| Event | Choreography | Constraint |
|---|---|---|
| Press → PENDING | feedback vehicle appears; ellipsis/spinner steps every ≥ 300 ms | immediate local ack; complete frames only |
| PENDING → FOCUSED | success mark, hold ≈ 800 ms, cut back to resting | success only on exact identity+generation ack |
| PENDING → failure | cause word in, holds until newer generation or bounded timeout | never auto-clears into implied success |
| Generation refresh | per-panel direct cut old-complete → new-complete, sequential, ≤ 250 ms total; bindings all-or-nothing after last flush | R-2; SYNC veil only for boot/reset/failure |
| Confirmed theme change | all three agent tiles repaint in the confirmed theme, then panel 4 repaints | no mixed-theme cluster or stale background pixels |
| State change on one tile | direct cut | no transition theater |
| BLOCKED persistent motion | 1.2 s breathing, in phase with LED pulse | privileged; present in every theme |
| Theme ambient motion | theme-specific, complete-frame scheduler in tick() | R-1 budget: ≤ 30 % of loop wall time measured; degrade to half cadence then static; never obscures semantic states; no per-frame allocation |
| Stale/offline onset | fence cut on all panels simultaneously | never rolling |

## Copywriting Contract

All Phase 2 state/result words remain the only vocabulary: `SYNC`, `EMPTY`, `NO AGENT`, `SLOT EMPTY` (Ledger only), `BLOCKED`, `UNSEEN`, `WORKING`, `IDLE`, `SETTLED`, `UNKNOWN`, `STALE`, `OFFLINE`, `UNAVAILABLE`, `PENDING`, `FOCUSED`, `REJECTED`, `VANISHED`, `UNCERTAIN`, `FAILED`. Menu adds: `THEME`, `LED`, theme names `SIGNAL EDGE` / `LEDGER` / `BEACON` / `INSTRUMENT`, grammar names `RAIL ECHO` / `EXCEPTION` / `FIELD EXT` / `METER+LAMPS`, bounded theme-specific turn/click hints, and panel-4 rest copy `CODEX`, `5H` / `WEEK` labels, `N/A`, and `UNAVAILABLE`. Uppercase ASCII, bounded, no credentials/paths/IDs on panels.

## Explicit Non-Goals

- Live Codex data, brightness control, health rows, diagnostics identifiers in the menu (Phase 3: MENU-02/03/04, CODEX-*).
- Any change to inbox ordering, focus semantics, protocol payloads, generation identity, or host authority.
- New display abstraction, LVGL, fonts, or remote assets; a second key/LED map; raw panel access.
- Full-cluster menu takeover; modal agent keys; wrap-around menu navigation.
- Persisting anything beyond confirmed theme + LED grammar enums.
