- `BoardAdapter::setLeds(hue, sat, brightness, logicalMask)` is the only output path; one HSV triple per call; multi-hue frames = multiple sequential calls (last write per index wins). `PhysicalMap::ledMask` translates logical→library; no raw indices.
- Physical zones (logical): backlights L1/L4/L7/L10/L13; above-key accents L0/L3/L6/L9; inter-key accents L2/L5/L8/L11/L12. Grammar zone assignments per UI-SPEC table.
- `LedGrammar` (new): `frame(const RenderState&, const LedEvents&, uint32_t now_us, Segment* out, size_t cap) -> size_t`. `LedEvents` carries per-slot feedback transitions (pending began, success, failure) and menu-open.
- `LedEngine` (new): clamps every segment against the power policy, tracks >25-brightness count, applies dim scaling and all-off, and rate-limits application to when segments actually change (avoid redundant I2C/LED traffic every loop tick).
- BLOCKED phase from plan 02's scheduler (wave-2 sibling: if plan 02 lands later, use a local 1.2 s epoch behind the same accessor signature agreed in RESEARCH; the accessor name `blockedPhaseEpochUs()` is the contract).
