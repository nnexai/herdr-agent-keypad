**User's choice:** Theme-specific decorative ambient motion with continuous animation; snappy focus feedback; atomic per-panel progressive reveal rather than an all-panel barrier.
**Notes:** The user clarified “atomic per panel—not necessarily atomic for all panels together.” This conflicts with the current no-decorative-animation rule, the design proposal's BLOCKED-only motion charter, Phase 02.1's discrete rendering budget, and SYNC-02's one-logical-generation invariant. These conflicts are recorded for explicit reconciliation before implementation; they were not silently treated as compatible.
