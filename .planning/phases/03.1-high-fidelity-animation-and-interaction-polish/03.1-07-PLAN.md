## Trust boundaries

ASVS level: L1. The plan treats build/upload results, device hello data, capture selectors, and evidence files as untrusted until each named validator succeeds.

| Boundary | Description |
|---|---|
| Completed source and binary → exact keypad | The final image crosses an exclusive USB flashing boundary and must not be confused with the Plan 01 baseline. |
| Exact keypad hello → deployment lock | Device-reported identity and session data must match the stored pair and just-built binary before becoming evidence authority. |
| Capture request → firmware fixture renderer | Host-controlled selectors enter a bounded diagnostic path and must not mutate authority or exhaust memory. |
| Deployment lock → logical manifest | Every logical row must retain the exact immutable deployment ID and lock checksum. |

## STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation plan |
|---|---|---|---|---|---|
| T-03.1-25 | Spoofing | `phase31-deploy-lock` exact-device identity | high | mitigate | Require exclusive ownership, stored pair, post-upload fresh hello, protocol/boot/session identity, and binary SHA-256 equality before deriving the deployment ID. |
| T-03.1-26 | Tampering | Final deployment and framebuffer evidence | high | mitigate | Atomic writes, canonical deployment ID, per-artifact SHA-256 sidecars, immediate reopen, and strict lock-to-manifest equality. |
| T-03.1-27 | Denial of Service | Capture selector and matrix runner | high | mitigate | Closed enum tokens, exact frame size, bounded matrix cardinality, timeouts, exclusive serial ownership, and no arbitrary frame stream. |
| T-03.1-28 | Elevation of Privilege | Diagnostic capture path | high | mitigate | Production renderer only, fixed fixture data, and native non-mutation checks for NVS, bindings, active selection, host state, and focus feedback. |
| T-03.1-29 | Information Disclosure | Deployment and logical evidence | medium | mitigate | Allowlist deployment/performance/presentation fields and reject credentials, account identity, prompts, transcripts, host paths, and raw opaque focus IDs. |
</threat_model>
