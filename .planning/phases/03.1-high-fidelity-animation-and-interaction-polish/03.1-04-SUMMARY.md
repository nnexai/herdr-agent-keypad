## Decisions Made

- The press impulse is presentation metadata only; it never changes the typed `focus_intent` payload or host action authority.
- Pending timing is projection-owned and fixed at 300 ms so theme ambient cadence and Static degradation cannot starve the request lifecycle.
- Exact success continues to require every existing correlation fence and `focused=true`; no transport-delivery shortcut or replay path was added.
