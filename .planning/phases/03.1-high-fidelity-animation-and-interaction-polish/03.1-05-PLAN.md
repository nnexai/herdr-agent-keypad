## Trust boundaries

| Boundary | Description |
|---|---|
| Encoder hardware → `MenuController` | Untrusted rapid/reversed deltas enter bounded row/value state. |
| Candidate preview → persisted settings/hardware brightness | Preview must not become stored state without explicit confirmation and must restore on close/timeout. |
| Menu state → direct focus path | Secondary menu presentation must not intercept or remap keys 1-3. |

|---|---|---|---|---|---|

| T-03.1-18 | Elevation of Privilege | Menu/direct key interaction | high | mitigate | Preserve pure `ProductInputRouter` ordering and unconditional `reportAgentKey`; menu owns no focus or arbitrary action. |
| T-03.1-19 | Denial of Service | Rapid encoder animation | high | mitigate | No queue/momentum, fixed duration/storage, immediate mutation, measured scheduler degradation, and hardware polling before repaint. |
