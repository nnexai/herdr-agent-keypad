## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Synthetic native timestamps could consume a newly-started transition before BLOCKED cadence was established.**
- **Found during:** Task 1 focused native regression.
- **Issue:** Native tests use deterministic timestamps that may precede the runtime `micros()` transition start; unsigned elapsed arithmetic treated that as an expired transition and suppressed the expected BLOCKED frame.
- **Fix:** Added signed wrap-safe transition elapsed checks so a timestamp before the start is neutral and does not preempt semantic/blocked work.
- **Files modified:** `firmware/src/ui/animation.h`
- **Verification:** Focused `native-agent-projection` environment passed all 75 tests.
- **Committed in:** `8712302`

**2. [Rule 1 - Bug] Static degradation could leave an active transition queued for later recovery.**
- **Found during:** Task 2 scheduler review.
- **Issue:** Returning from Static to Half/Full could otherwise resume stale decorative progress.
- **Fix:** Static selection now interrupts and clears transition progress while preserving the presentation epoch.
- **Files modified:** `firmware/src/ui/animation.h`, `firmware/src/app/agent_projection.cpp`
- **Verification:** Focused native tests and selected USB build passed.
- **Committed in:** `8712302`

**3. [Rule 2 - Missing Critical] Focus outcomes were not rendered immediately on transport result.**
- **Found during:** Task 2 semantic preemption review.
- **Issue:** `applyFocusResult` updated feedback state, but the main loop could wait for a scheduler cadence before flushing success, failure, or uncertainty.
- **Fix:** Main now compares the bounded feedback enum before/after an admitted result and immediately flushes the affected complete tile when it changes; identity and focus correlation remain unchanged.
- **Files modified:** `firmware/src/main.cpp`
- **Verification:** Selected USB firmware build passed; native projection regressions remained 75/75.
- **Committed in:** `a9a8936`

**Total deviations:** 3 auto-fixed (Rule 1: 2, Rule 2: 1)
