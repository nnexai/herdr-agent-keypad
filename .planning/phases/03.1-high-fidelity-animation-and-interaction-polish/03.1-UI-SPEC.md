# Phase 03.1 — UI Design Contract

> Contract for measured motion and interaction polish on the exact LILYGO T-Keyboard S3 Pro. This extends the Phase 02.2 visual contract and the Phase 3 Codex/menu contract; it changes presentation only, never host authority, generation identity, freshness semantics, or the direct focus-only action.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — embedded C++ firmware, LovyanGFX primitives, and the existing reusable 128×128 RGB565 composition sprite |
| Preset | not applicable |
| Component library | none; retain `AgentProjection`, `AnimationScheduler`, `ThemeRenderer`, `LedEngine`, `MenuController`, `BoardAdapter`, and `PhysicalMap` seams |
| Icon library | none; geometric primitives drawn locally: rail, dash, dot, triangle, ring, corner, question, cross, broken-link, check, spinner, hatch |
| Font | existing bundled bitmap mono family; regular and semibold only; no runtime font, emoji, remote asset, LVGL, or second display abstraction |

The shadcn gate does not apply. This is a fixed embedded surface, not React/Next/Vite. All panels remain 128×128 pixels with a 4 px safe inset, are composed completely before sequential flush, and are addressed only through the verified board abstraction. Existing 02.2 palettes, geometry, state words, four themes, four LED grammars, and Phase 3 Codex/menu behavior remain authoritative unless this contract explicitly adds motion around them.

### Non-negotiable semantic boundary

- Keys 1–3 are immediate, direct, non-modal focus-only paths even while the encoder menu is open or any animation is running. They are polled immediately after `board.update()` and before USB admission, animation, menu, or LED work.
- A press impulse means only that the physical press was detected. `PENDING` means an accepted current-generation request is in flight. `FOCUSED` means exact Herdr acknowledgement of the opaque target, host epoch, and snapshot revision.
- A stale/offline/SYNC/failure fence asserts immediately; no decorative transition may delay it. No uncertain press is queued, replayed, or optimistically retried.
- Every animated display result is one complete frame in the existing sprite. No partial drawing, per-frame allocation, mixed-generation pixels, or binding activation before the safe commit.

---

## Hardware and Fixed Geometry

- Four independent panels are exactly 128×128. Keep every pixel inside the 4 px safe inset and retain the established per-theme geometry and text budgets.
- Agent tiles occupy fixed physical positions 1–3. Empty slots remain in place and never collapse. Panel 4 remains the Codex/read-only surface at rest and the encoder menu surface while open.
- Sequential ordinary refresh may reveal old-complete → new-complete panels, but the whole reveal must finish within 250 ms and bindings remain fenced until every panel has flushed. Boot, reset, session failure, and reconnect start with the all-panel `SYNC` presentation.
- Key and LED mapping is the verified `PhysicalMap`: backlights L1/L4/L7 for agent keys, L10 for Codex/K4 usage, L13 for encoder; above-key accents L0/L3/L6/L9; inter-key accents L2/L5/L8/L11/L12. Do not infer or introduce another map.

## Shared Motion and Transition Contract

### Timing and interruption

| Event | Exact behavior |
|---|---|
| Physical agent-key press | Within one main-loop turn, show one complete-frame press impulse; target ≤80 ms from detected press, hard maximum 120 ms. The impulse lasts one frame or 80 ms, whichever is shorter, then enters `PENDING`. |
| `PENDING` | Localized continuous cue; spinner/sweep/ellipsis advances every 300 ms. Identity, title, discriminator, and state word remain spatially fixed. Deadline is 3 s; timeout becomes `UNCERTAIN`. |
| Exact focus success | Theme-specific flourish begins on acknowledgement, then `FOCUSED` remains for 800 ms (hard maximum 900 ms) before returning to resting state. Success never appears on transport delivery alone. |
| Rejected/vanished/stale/offline/failed/uncertain | Assert in the first complete frame after classification. Hold for 2 s or until a newer authoritative complete generation supersedes it; never auto-clear into implied success. |
| Ordinary live-data replacement | Theme-specific semantic transition, 200 ms target and 250 ms hard maximum. It is interruptible by a newer generation or urgent fence; no transition queues old data. |
| Stale/offline/SYNC/safety fence | Immediate cut on every affected panel; no fade, blend, or waiting period. Keys are fenced before or at the first fence frame. |
| Safe reconnect/recovery | Keep all-panel `SYNC` until the complete generation is validated and bindings remain fenced through flush. Reveal the four panels in theme-specific staged cuts over 200 ms target, never beyond 250 ms total; no celebratory flourish. |
| Encoder detent | Cursor/value changes in the same input turn before any spatial easing. One detent moves exactly one bounded row/value; no momentum, inertial scroll, wrap, or coalescing. |
| Menu open/close and click | Immediate visible response in the first complete frame; optional 120 ms spatial settle follows but never gates input. |
| Menu row/detail slide | 160 ms target, 200 ms hard maximum; rotation direction is spatially obvious. A reversed detent reverses direction rather than continuing momentum. |
| Brightness preview | Apply each 10% step (10–100%) immediately in the same input turn; no decorative delay. Click confirms; close or 30 s timeout restores the stored value. |
| Blocked pulse | Fixed 1.2 s cycle, 600 ms high/600 ms low, display and corresponding grammar pulse share the scheduler epoch. It is the last animation to degrade under pressure. |

Urgent events interrupt ambient motion and ordinary transitions. Once interrupted, the semantic frame wins; do not blend through an ambiguous intermediate color or partial state. Motion changes hierarchy, never truth.

### Resource and degradation contract

- Nominal ambient scheduler level is `Full`; if measured projected animation duty exceeds 30% of loop wall time, change to `Half` (cadence doubled); if still over budget, change to `Static` (ambient disabled). Recovery toward full cadence is allowed only after measured load is comfortably within budget.
- The 30% duty rule includes complete compose plus panel flush. There is no per-frame heap allocation. `AnimationScheduler`, theme renderers, LED grammar frames, and transition progress use bounded storage.
- `Half` preserves all semantic frames and feedback timing while doubling only ambient cadence. `Static` removes decorative ambient and interpolation but retains complete, fully legible semantic, menu, Codex, focus-result, fence, and `SYNC` frames. The literal state word, glyph, geometry, and truthful age/value remain.
- If a complete frame cannot meet the budget, skip decorative work before skipping input or semantic feedback. Never starve key polling, delay a fence, expose a mixed generation, or leave an in-between brightness/menu preview on screen.
- No user-facing reduced-motion switch is added in this phase. Reduced/degraded behavior is the measured scheduler path and is also the required static capture mode for evidence. A static frame is a valid presentation, not an error.

## Theme Motion Signatures

Stable titles, state words, values, identity, and primary semantic geometry do not move. Each theme has its own accent layer and intentional animated-state set; do not apply one shared pulse to all themes.

| Theme | Nominal ambient signature | Animated states | Intentionally static states and fences |
|---|---|---|---|
| Signal Edge | Rail/signal accents: four-phase 800 ms dash advance on the rail or short signal markers; no title motion. | `BLOCKED` 1.2 s rail pulse; `UNSEEN` stripe advance; `WORKING` short directional signal sweep; `PENDING` localized rail sweep; `FOCUSED` check flourish. | `IDLE`, `SETTLED`, `UNKNOWN`, `EMPTY`; Codex/menu values stable; `STALE`, `OFFLINE`, `SYNC`, and all failures cut immediately. |
| Ledger | Typographic record motion: four-phase 1.2 s underline/row reveal or one-row highlight travel; words and row baselines fixed. | `BLOCKED` inversion band pulse; `UNSEEN` double underline advance; `WORKING` underline sweep; `PENDING` header/row progress cue; `FOCUSED` check/underline settle. | `IDLE`, `SETTLED`, `UNKNOWN`, `EMPTY`; no animated stale/offline header; `SYNC` is a stable record veil. |
| Beacon | Field/beacon motion: eight-phase 1.6 s low-contrast field breath or beacon halo shift, quantized to avoid RGB565 banding. | `BLOCKED` field/glyph breath; `UNSEEN` restrained halo breathe; `WORKING` directional beacon sweep; `PENDING` localized center sweep; `FOCUSED` beacon mark settle. | `IDLE`, `SETTLED`, `UNKNOWN`, `EMPTY`; source fences, `SYNC`, and unavailable data are static stepped fields with a fixed reason. |
| Instrument | Gauge motion: eight-phase 1.0 s ring marker sweep or tick movement, with ring center and state word fixed. | `BLOCKED` dashed ring pulse; `UNSEEN` double-ring marker travel; `WORKING` gauge sweep; `PENDING` ring segment spinner; `FOCUSED` ring/check settle. | `IDLE`, `SETTLED`, `UNKNOWN`, `EMPTY`; `STALE`, `OFFLINE`, `SYNC`, and failures use immediate static bezel/veil treatment. |

Theme primitives may move only when the motion matches the metaphor and leaves identity legible. The exact phase table is deterministic and captureable; `Half` samples every second phase and `Static` uses the neutral/static phase.

### Agent tile state grammar

All four themes render the complete state vocabulary: `BLOCKED`, `UNSEEN`, `WORKING`, `IDLE`, `SETTLED`, `UNKNOWN`, `EMPTY`, `PENDING`, `FOCUSED`, `REJECTED`, `VANISHED`, `STALE`, `OFFLINE`, `UNCERTAIN`, `FAILED`, and `SYNC`. Every state has a literal word plus geometric cue; no state is represented by motion or color alone. Occupied title and `workspace·tab` discriminator remain fixed and tail-ellipsized within the 8 px metadata floor. Empty tiles show `EMPTY` and `NO AGENT`; they never retain an old occupant.

## Codex Tile and Health Motion

Panel 4 remains read-only at rest. Across every theme it shows fixed primary and secondary integer used percentages when supplied, `N/A` for absent/null windows, nearest supplied reset (`RESET N/A` if neither exists), `LIMIT` only when reached-limit is supplied, and visible observation age. The following motion is permitted only around stable values:

- Signal Edge: usage rails may advance one bounded segment on a current observation; reset and percentage text never scroll.
- Ledger: current usage rows may receive a single restrained underline settle on a new observation; no number ticker/counting animation.
- Beacon: current gauges may make one low-contrast field/marker settle; no continuous motion when data is stale or unavailable.
- Instrument: gauge/needle may make one bounded sweep to the new value; the numeric percentage and limit word cut in immediately.

`STALE` or `OFFLINE` veils, `AUTH REQUIRED`, `CODEX OFFLINE`, `HOST OFFLINE`, `UNAVAILABLE`, and unknown/null values assert immediately and disable any misleading ambient value animation. Keep last complete values only under an unmistakable veil with observation age; if no complete observation exists, render state plus `N/A` fields only. Never animate from `N/A` to a fabricated zero or show an `OK` cue for missing reached-limit data.

## Encoder Menu and Brightness Preview

The menu is the bounded six-row root list: `THEME`, `LEDS`, `BRIGHTNESS`, `HEALTH`, `ABOUT`, `CLOSE`. It shows a three-row window around a clamped cursor. Encoder click opens/closes, enters a row, confirms an edited value, returns from read-only detail, or activates `CLOSE`; no long press or double click exists.

- Root open uses a 160 ms spatial slide into panel 4; keys 1–3 remain direct focus paths and their feedback remains on the agent tile and mapped LED zone.
- Each detent moves one row immediately; the visible row follows encoder direction. A detail page slides from the corresponding side in 160 ms, while its first response appears immediately.
- `THEME` and `LEDS` use preview-then-confirm. Candidate theme renders menu presentation only; candidate LED grammar is driven live. Click confirms and persists; close/cancel/timeout reverses the preview visibly and restores the stored setting.
- `BRIGHTNESS` starts at stored value, changes in 10% steps from 10% through 100%, and updates hardware immediately. No 0% state exists. Confirmation persists only the explicit value; cancel/timeout restores the previous stored value.
- `HEALTH` and `ABOUT` are read-only and spatially related to the root. Live health updates never move the cursor or reset the 30 s inactivity timer.
- After 30 s without encoder activity, close and discard any unconfirmed preview. No transition may delay the timeout's visible close/revert.
- Theme-specific menu metaphors remain: Signal Edge rail and full-row selection band; Ledger `>` cursor and ledger rows; Beacon large row words; Instrument bezel and bounded turn/click hints. Copy stays inside the 4 px inset.

## LED Grammars and Display Coordination

Display and LED motion synchronize at semantic moments — press, `PENDING`, `FOCUSED`, rejection/failure, blocked, menu-open, stale/offline health, and `SYNC` — but ambient phases may differ. Ordinary state/menu/success changes may blend; blocked, stale/offline, rejection, failure, and uncertainty assert immediately. Preserve each grammar's restraint; never add a universal resting breath.

| Grammar | Resting and animated behavior | Health/fence | Focus/menu feedback |
|---|---|---|---|
| Rail Echo | L1/L4/L7 mirror tile state (BLOCKED 40 pulse, UNSEEN 30, WORKING 18, IDLE 8; others off); improve rail-aligned dash/pulse transitions without changing zones. | All backlights dim red ≤10 in unison, immediate; old state is not blended through health. | Press/PENDING cyan 45 on the pressed zone; FOCUSED lime two-pulse; failure red two-pulse; L13 lit while menu open. |
| Exception Channel | Intentionally dark at rest except BLOCKED rose 30 pulse and UNSEEN blue 20; no ambient breath or unrelated transition. | L0/L3/L6/L9 above-key accents dim red 10 immediately; backlights retain their state language. | One short pressed-zone blink for pending/success/failure; L13 menu cue. |
| Field Extension | Three-LED halos per key (K1 0–2, K2 3–5, K3 6–8, usage 9–11) use state hue; backlight brightest, halo 40/60%; bounded ladder 38/28/16/8. Pending may sweep 0→1→2. | Halos off; encoder pair L12–L13 breathes red 10, with health winning over menu. | Pending halo sweep, solid lime two-pulse success, red two-pulse failure; menu L13 only when health does not own it. |
| Meter + Lamps | Backlights follow Rail Echo; usage meter accents L0/L2/L3/L6 remain off when no honest usage data exists; L5/L8/L9/L11/L12 stay dark. No universal life effect. | Lamps unison dim red ≤10, immediate; meter remains dark. | Grammar-A-like pressed/pending/success/failure lamp cues; L13 menu cue; meter never implies unavailable Codex data. |

Global LED limits remain: cap 45; resting total ≤25; at most six LEDs above 25 simultaneously; no persistent white; health red ≤10; dim mode scales all to ≤8; all-off is one mask write. LED interpolation is bounded and allocation-free. Display/LED semantic transitions use the same event epoch, not necessarily identical frame phases.

## Focus Feedback State Machine

| Feedback | Immediate visual | Duration/exit | Truth constraint |
|---|---|---|---|
| Press impulse | One-frame geometric compression/flash in the pressed tile and its own LED zone | one frame/≤80 ms, then `PENDING` | physical press only; never success |
| `PENDING` | theme-local spinner, sweep, or traveling accent; fixed identity/state text | 300 ms cue steps until result or 3 s deadline | request is current-generation and not yet acknowledged |
| `FOCUSED` | theme-specific check/flourish and lime LED cue | 800 ms target, then resting | exact opaque identity + epoch + revision acknowledged by Herdr |
| `REJECTED` | cross/failure vehicle and red zone | 2 s or newer generation | empty/stale/invalid/incompatible action was not sent or accepted |
| `VANISHED` | broken-link vehicle and red zone | 2 s or newer generation | exact target disappeared; never substitute new occupant |
| `STALE`/`OFFLINE` | immediate hatch/broken-link fence | until fresh complete generation/source recovery | key disabled, no queue/replay |
| `UNCERTAIN` | question/amber vehicle | 2 s or newer generation | no exact acknowledgement; never retry automatically |
| `FAILED` | cross-over-buffer vehicle and red zone | 2 s or newer generation | protocol/host failure, not an implied Herdr success |

A native Herdr focus may produce documented seen/manual-unread effects. The device never settles, dismisses, replies, approves, acknowledges, or invokes an arbitrary action, and never locally reorders tiles after focus.

## Accessibility and State Legibility

- Every state has at least three redundant channels where applicable: literal word, geometric form/layout, and semantic color. Motion is a fourth optional cue, never required for comprehension.
- `Full`, `Half`, and `Static` frames all retain state words, values, ages, identity, fences, and focus safety. A user observing only one static frame must distinguish current, empty, stale, offline, unavailable, pending, success, and failure.
- Keep title/discriminator and state words spatially stable during ambient motion and pending. Never ticker-scroll identity or animate numbers through intermediate values.
- Preserve the established contrast target: primary text `#F8FAFC`, metadata `#CBD5E1` or brighter as needed, at least 4.5:1 against its immediate surface. Verify colored cues independently because color is not the sole signal.
- Keep the 8 px bitmap metadata floor and 4 px inset at the lowest accepted brightness. Tail ellipsize long titles/discriminators with `...`; do not clip, overlap, shrink, or cross the bezel.
- Rapid encoder detents, menu open/detail transitions, brightness changes, agent presses, and simultaneous Herdr/Codex updates must not starve input or cause focus remapping. Input causality is visible before easing.
- A reduced/degraded capture is not a hidden accessibility mode: it is a complete, truthful static presentation and must be validated with the same state matrix.

## Exact-Device Quality Evidence

Phase acceptance requires both logical framebuffer evidence and observation on the exact paired keypad; neither substitutes for the other.

### Logical capture matrix

Use deterministic RGB565 `capturePanel()` fixtures and contact sheets for all four themes and all four LED grammar selections. Capture: every occupied agent state; empty zero/one/two/three-slot layouts; `PENDING`, `FOCUSED`, every failure/fence word; `SYNC`; Codex current with both windows/reset/limit; Codex null/unavailable/auth/offline/stale with age; menu root/detail/health/about/close; theme and LED preview/confirm/revert; brightness at 10%, 80%, and 100%; nominal, `Half`, and `Static` frames. Inspect pixels for geometry, clipping, overlap, palette, hatch, text floor, complete composition, and no mixed-generation binding.

### Physical observation matrix

On the same verified unit, exercise all 16 theme/grammar combinations under: ordinary refresh, rapid encoder detents/clicks, rapid direct agent presses, concurrent Herdr/Codex updates, blocked motion, pending/success/failure, stale/offline transitions, reconnect, reset, and brightness preview/revert. Record:

- exact physical display orientation, viewing angle, brightness/legibility, LED zone correctness, blend artifacts, tearing, black flashes, ghosting, and subjective smoothness;
- first visible press impulse latency and encoder response latency (target ≤80 ms, hard maximum 120 ms for first impulse); maximum key-poll gap during motion;
- complete compose+flush time, animation duty, frame cadence, skipped/degraded frames, and scheduler level changes;
- free heap/largest block, bounded queue/high-water marks, and evidence of zero per-frame allocation;
- simultaneous display/LED semantic event alignment and absence of input starvation.

Hard acceptance invariants are: complete frames only; no mixed generations; no black flash or tearing; no focus action during a fence/reveal; no queued/replayed press; animation duty ≤30% of loop wall time; reveal ≤250 ms; input remains responsive under concurrent source updates; degradation reaches `Half` then `Static` before budget violation; static mode remains semantically complete. Any visual defect receives a traceable capture/observation ID and is fixed or explicitly blocks acceptance. Evidence must preserve failed and degraded runs rather than relabeling them as passes.

## Explicit Non-Goals

- No new controls, encoder gestures, agent actions, provider collectors, or host authority changes.
- No changes to inbox ordering, opaque focus identity, host epoch, snapshot revision, freshness policy, protocol envelope, panel/key map, or direct focus-only semantics.

- No universal breathing effect, unbudgeted decoration, inertial scrolling, ticker text, animated numeric counting, or transition that delays an urgent truth state.
- No user-configurable reduced-motion setting in this phase; bounded measured `Full`/`Half`/`Static` behavior is the presentation contract.
