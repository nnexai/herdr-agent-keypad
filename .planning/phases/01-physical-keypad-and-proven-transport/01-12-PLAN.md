## Trust Boundaries

| Boundary | Description |
|---|---|
| Real traffic/clock → qualification result | Measurements determine transport eligibility. |
| Operator interruption → required row | Physical actions cannot be inferred from labels or generic reconnects. |
| Evidence directory/pointer → USB lock | Mutable, escaped, incomplete, or semantically false files must fail. |
| USB result → Wi-Fi eligibility | Only repeatable strict remediated failure may cross the fallback gate. |
