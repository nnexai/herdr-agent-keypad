The closed object contains only `source_state`, nullable `used_credits`, nullable `included_credits`, nullable `used_percent`, `reset_text`, `observation_age`, `unlimited`, nullable `reached_limit`, nullable `usage_allowed`, nullable `overage_allowed`, and the allowlisted `failure_reason`. - Provider eligibility means displayable capacity, not merely object presence. Codex is eligible when its state permits retained values and either percentage exists. Current/stale retained data must keep its truthful state word. `auth_required` and `unavailable` without values are ineligible.
- Selection is symmetric: one eligible provider is selected immediately and held; two eligible providers retain the currently selected provider for a full `kUsageProviderPeriodUs = 8'000'000` microseconds and then toggle with equal dwell; zero eligible providers select `UsageProvider::None` immediately. When there is no eligible current provider and both become eligible in the same snapshot, use snapshot-revision parity as the provider-neutral deterministic tie-break, and test both parities.
- Any eligibility loss preempts the timer: select the remaining provider or neutral view in the same committed generation, compose one complete off-screen panel-4 frame, push it once, and restart a full dwell. Copilot appearance while an eligible Codex view is selected does not cut the Codex dwell short. Use the existing wrap-safe elapsed helper. While the menu is open, postpone the semantic deadline so rotation cannot overwrite the menu and closing it gets a full dwell.
- `CODEX` keeps the existing 5H/WEEK rows. `COPILOT` uses provider-specific USED/INCL AIC rows, a bounded percentage cue when present, `UNLIM` without an invented denominator, existing reset/age metadata, and CURRENT/STALE/LIMIT/ALLOWED/OVERAGE/AUTH REQUIRED/UNAVAILABLE truth vocabulary as applicable. A hard LIMIT is shown only when exhausted use is not allowed. The neutral view is labelled `USAGE` and `UNAVAILABLE`, clears all capacity values, and may show only bounded cause text such as `C AUTH`, `C N/A`, `P AUTH`, or `P N/A`.
- Reuse the existing palette and each theme's current panel-4 geometry. Provider transitions are semantic full frames, not ambient animation: fill only the off-screen sprite, never flush a blank/cleared hardware panel, and perform exactly one display-4 push per change. Leave all LED grammar and `ledCodexCue` behavior unchanged.
