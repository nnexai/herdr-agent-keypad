# Restore the permanent bridge automatically after USB CDC reset

<objective>
Keep the existing `PermanentBridge` process useful when the paired Espressif CDC interface disconnects and re-enumerates: fence focus immediately, retry the existing exact-device connection with bounded backoff, rebuild authoritative Herdr/event-stream state, publish and receive acknowledgement for one complete current three-slot snapshot, and only then resume readiness and focus.

Purpose: Fix the observed alive-but-disconnected state without restarting the bridge, weakening paired-device identity, adding a dependency, or introducing another transport abstraction.
Output: Focused recovery regressions and a production recovery path in the existing bridge/USB session seam, followed by an actual-device recovery check.
</objective>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Linux USB candidates → stored pairing | USB descriptors are discovery hints; only the stored opaque identity plus fresh application hello may authorize a session. |
| Device session → bridge focus executor | Device frames are untrusted until their boot/session, host epoch, snapshot revision, slot, entry ID, and opaque identity match the current acknowledged generation. |
| Bridge → Herdr public socket | Recovery may read public authoritative state and invoke only the already-allowed `agent.focus` action for a fresh exact intent. |
